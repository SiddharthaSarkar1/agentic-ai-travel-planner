# Agentic Travel Planner

This project is a multi-agent AI system for planning travel itineraries. It uses a FastAPI backend and a series of specialized agents to gather information about flights, hotels, weather, and currency exchange rates.

## Features

*   **Automated Flight Search:** Fetches live flight data using the AviationStack API.
*   **Hotel Recommendations:** Provides hotel suggestions using the Tavily web search API.
*   **Weather Forecasts:** Gets real-time weather information from the OpenWeather API.
*   **Currency Exchange:** Converts currencies using the Frankfurter API.
*   **Detailed Itinerary Generation:** Creates a day-by-day itinerary based on the user's request.
*   **Persistent Conversations:** Remembers previous interactions using a PostgreSQL database, allowing users to continue their travel planning across multiple sessions.

## Architecture

The application is built on a multi-agent architecture using LangGraph. Each agent is a specialized function that performs a specific task:

1.  **Flight Agent:** Searches for flights based on the user's query.
2.  **Hotel Agent:** Finds the best hotels for the user's destination.
3.  **Itinerary Agent:** Creates a detailed itinerary.
4.  **Currency Agent:** Fetches currency exchange rates.
5.  **Weather Agent:** Gets the weather forecast for the destination.
6.  **Final Agent:** Compiles all the information into a comprehensive travel plan.

The agents are connected in a graph, and the state is passed from one agent to the next. The final response is generated by the `final_agent` and returned to the user.

## API Endpoints

### `/api/travel`

*   **Method:** `POST`
*   **Description:** The main endpoint for interacting with the travel planner.
*   **Request Body:**

```json
{
  "message": "I want to go on a 5-day trip to Paris from New York.",
  "thread_id": "user_12345" 
}
```

*   **Response:**

```json
{
  "success": true,
  "thread_id": "user_12345",
  "answer": "...",
  "flight_results": "...",
  "hotel_results": "...",
  "itinerary": "...",
  "llm_calls": 6
}
```

## Tools and Technologies

*   **Backend:** FastAPI
*   **AI/LLM:** LangChain, LangGraph, Google Generative AI (Gemini)
*   **Database:** PostgreSQL
*   **APIs:**
    *   AviationStack (Flights)
    *   Tavily (Web Search)
    *   OpenWeather (Weather)
    *   Frankfurter (Currency)
